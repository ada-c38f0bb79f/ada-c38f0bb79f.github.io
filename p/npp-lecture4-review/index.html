Lecture 4 复习：Python Data Structures & Classes（面向对象与深度学习）

主题：内置数据结构 · 可变/不可变 · 标准库扩展类型 · 类与继承 · 魔法方法 · PyTorch nn.Module 讲师：Dr. Tom Davison（Data Structures）· Debbie Pelacani Cruz（Classes & Deep Learning）

第一部分：核心数据结构

1. 对象与名字绑定

  • 所有 Python 数据都是「对象（object）」。
  • Python 用鸭子类型：函数接受任意对象作为输入（不像 C/Java）。
  • 用 = 把对象绑定到名字。
x = 7
y = x          # y 和 x 指向同一个对象
a = list([1,2,3,4])
b = a          # b 和 a 指向同一个 list 对象（浅绑定！）

2. 可变 vs 不可变（Mutability）

类型 可变性
int / float / str / complex / tuple / frozenset 不可变（immutable）
list / set / dict 可变（mutable）
  • 「更新」不可变对象其实是在新建对象，用 id() 可验证。
x = 3
print(id(x)); x += 5; print(id(x))   # id 改变 → 新对象
  • 小整数缓存：Python 缓存 -5 到 256 的整数对象。
x = 3; y = 3
print(x is y)          # True（同一缓存对象）
a = 12345; b = 12345
print(a is b)          # False
  • Python 整数任意精度，上限受内存限制（sys.getsizeof() 看占用）。

3. 列表（list）

  • 用 [] 或 list() 创建：[1,3,5]、list((3,4,5))、[_ for _ in range(6,10)]。
  • 特点：可变、一维（单索引）、有序，是其它对象的集合，支持迭代。
  • 快：查找/改元素、增删末尾元素。
  • 慢：增删非末尾元素（与长度成正比，因为要整体搬移）。
  • 实现：CPython 的 list 是一块存「内存地址」的内存块；预留空间扩展，满了要整体拷贝。

列表推导式（list comprehension）

  • [ _ for _ in range(6, 10) ]，通常是最快的建 list 方式（比 for+append 快 20–25%），在可读范围内优先用。

4. 元组（tuple）

  • 用逗号（常配 ()）或 tuple() 创建：1,3,5、(2,3,4)、tuple([3,4,5])。
  • 特点：不可变、一维、有序，是 list 的不可变等价物。
  • 快：查元素；比 list 略省内存（块大小固定，无需预留扩展空间）。
  • 已知不会变就用 tuple。
  • 解包（unpacking）：a, b, c = 1, 2, 3，常用于接收函数返回的多值。

5. 生成器（generator）

  • 没有「tuple 推导式」；(x**2 for x in range(3)) 是生成器。
  • 只能迭代一次，不存内容，用的时候才生成、用完丢弃 → 省内存。
  • 易混淆：
gen = (x for x in range(4))
print(list(gen))   # [0, 1, 2, 3]
print(list(gen))   # []（已经耗尽！）

6. 集合（set）与 frozenset

  • 用 {} 或 set() 创建：{1,3,5}、set([3,4,5])。
  • 特点：无序、可变，是去重对象的集合。
  • x in S 极快（比 list 快一两个数量级）。
  • 实现：哈希表（hash table）。一个大块（大部分为空）+ 哈希函数映射到 0..N-1。
    • 加成员：算哈希 → 插入对应位置。
    • 查成员：算哈希 → 查对应位置。
    • 冲突（collision）：两个输入哈希到同一位置，Python 按可预测模式继续找下一块，直到找到目标或空位。→ 所以 set 需要比较空、比 list 费内存。
  • frozenset：set 的不可变版本。

7. 字典（dict）

  • 映射 key → value：{"a":1,"b":10}、dict(x=1,y=2)、{x:x**2 for x in range(10)}。
  • 和 set 一样优化了 x in D（快一两个数量级）。
  • key 必须不可变且可哈希（不能用 list 当 key）。
  • 实现：和 set 类似的哈希表；区别是：
    • dict 同时存 key 和（value 对象的地址）。
    • dict 保留插入顺序（Python 3.7+），set 不保留。
  • 字典推导式建 dict 快，但不总是比 for 循环快（如反转字典两者差不多）。

8. 如何选择数据类型

  • 需要有序 + 可变 + 索引 → list；不变 → tuple。
  • 需要去重 / 快速 in 判断 → set；不变 → frozenset。
  • 需要 key→value 映射 / 快速查 key → dict。
  • 需要节约内存、只遍历一次 → generator。

第二部分：标准库扩展类型

9. array 模块

  • 存同类型数据的集合，比 list 省内存（直接存值而非存对象地址）。
  • 但难用，大多数人忽略它；日常用 numpy 更好。
import array
a = [1,2,3,4,5]
b = array.array('b', a)   # 更省内存

10. collections 模块

类型 说明
namedtuple 类似 tuple 但有命名字段
deque 类似 list，但头尾增删都快
OrderedDict 记住插入顺序的 dict（现在普通 dict 也保序，多出现在旧代码）
defaultdict 缺 key 时用工厂函数自动给默认值，如 defaultdict(int)

第三部分：numpy / pandas 回顾

  • numpy.ndarray：多维数组（1D~64D），所有元素必须同类型；未指定 dtype 时自动推断能覆盖所有输入的类型。
np.array([0,1,2])     # int64
np.array([0,1,2.5])   # float64
np.array([0,'hat',sum])  # object
  • pandas.Series：带标签的一维数组；pandas.DataFrame：带索引和列名的表。
  • 详见 Lecture 2。

第四部分：Python 类（Classes）

11. 面向对象与封装

  • 类 = 自定义数据结构：**数据（属性）+ 修改它的函数（方法）**绑在一起。
  • 好处：封装（Encapsulation）——把数据和方法绑定，减少把数据/方法用错对象的错误。
class MyClass:
    """This is my cool class."""
    def my_method(self, a, b):
        self.val = a + b     # 存实例属性
        return a * b

inst = MyClass()             # 用 () 创建实例
a = inst.my_method(1, 2)     # a=2，inst.val=3

12. __init__ 与实例属性

class Point3D:
    def __init__(self, x, y, z):
        self.x = x; self.y = y; self.z = z

p = Point3D(1, 4, 7)
print(p.x, p.y, p.z)   # 1 4 7

13. 类属性 vs 实例属性（⚠️ 常见坑）

  • 类属性（写在 class 体、不在方法里）：所有实例共享同一个对象。
  • 实例属性（self.xxx）：每个实例各自独立。
class MyClass:
    mylist = []            # 类属性，所有实例共享！

inst1, inst2 = MyClass(), MyClass()
inst1.mylist.append(1); inst2.mylist.append(2)
print(inst1.mylist is inst2.mylist)   # True（同一个 list！）

可变类型（如 list）当类属性特别危险，因为实例间会互相影响。

14. 继承（Inheritance）

class MySubClass(MyBaseClass):
    '''继承 MyBaseClass'''
    # 新增方法
  • 所有类最终都继承自基类 object（int、list 也一样）。
  • 子类可**重写（override）**父类方法。
  • 查基类：Tree.__base__。
  • super()：在子类里调用父类的方法，避免重写整个函数。
class Shrub(Tree):
    def __init__(self, species, age, height, fruit):
        super().__init__(species, age, height)   # 调用父类 __init__
        self.fruit = fruit

15. property：让函数「像属性」

class Temperature:
    def __init__(self, temp):
        self.celsius = temp

    @property
    def fahrenheit(self):
        return self.celsius * 9/5 + 32

    @fahrenheit.setter
    def fahrenheit(self, temp):
        self.celsius = (temp - 32) * 5/9

16. 魔法方法（magic/special methods）

触发 方法
inst() __call__(self)
print(inst) __str__(self)
inst（交互式显示） __repr__(self)
inst1 + inst2 __add__（运算符重载）
  • 重载规则：别让人惊讶——+ 应该是加/增/追加，- 应该是减/删。

17. __new__ 与 __del__（进阶，可先忽略）

  • 创建实例时先调 __new__ 再调 __init__（一般只需写 __init__）。
  • __del__ 在垃圾回收认为对象不再需要时调用，用于清理特殊资源。

第五部分：类与深度学习（PyTorch）

18. 从神经元到 PyTorch

基础神经元（线性模型：加权求和 + bias）：

class Neuron:
    def __init__(self, weights, bias):
        self.weights = weights; self.bias = bias
    def forward(self, inputs):
        return sum(w*i for w,i in zip(self.weights, inputs)) + self.bias

用继承加激活函数（ReLU / Sigmoid）：

class ReLUNeuron(Neuron):
    def relu(self, x): return max(0, x)
    def forward(self, inputs):
        return self.relu(super().forward(inputs))   # 父类算线性，再套激活

19. PyTorch 的 nn.Module

  • PyTorch 中一切「神经网络」都继承自 torch.nn.Module，它管理参数、设备移动、保存/加载、autograd。
  • 关键点：
    • super().__init__() 初始化父类。
    • nn.Linear 自动注册可学习参数。
    • forward 定义计算。
class CustomNeuron(nn.Module):
    def __init__(self, input_size):
        super().__init__()
        self.linear = nn.Linear(input_size, 1)
        self.relu = nn.ReLU()
    def forward(self, x):
        return self.relu(self.linear(x))

多层感知机（MLP）：

class TinyMLP(nn.Module):
    def __init__(self, input_size, hidden_size, num_classes):
        super().__init__()
        self.fc1 = nn.Linear(input_size, hidden_size)
        self.act = nn.ReLU()
        self.fc2 = nn.Linear(hidden_size, num_classes)
    def forward(self, x):
        return self.fc2(self.act(self.fc1(x)))

20. Key Takeaways

  • 类封装数据（属性）与行为（方法）。
  • 继承让你定义一次通用蓝图，在子类里特化行为。
  • PyTorch 处处用这个模式：模型和层都继承 nn.Module，提供参数管理、设备管理、autograd 集成。
  • 理解类与继承 → 深度学习框架更透明，模型更易设计、调试和扩展。

易错点提醒 ⚠️

  1. 可变类型（list/dict/set）当类属性会在实例间共享，通常应放 __init__ 里当实例属性。
  2. 生成器只能迭代一次。
  3. a = b 对可变对象是浅绑定（同一对象），改 a 会影响 b。
  4. dict 的 key 必须不可变且可哈希。
  5. 子类要扩展（而非完全重写）父类逻辑时用 super()。
