Lecture 2 复习：NumPy & Pandas

主题：NumPy 数组 · 向量化运算 · 广播 · Pandas Series/DataFrame · 数据清洗 · 分组聚合 · 合并 · 时间序列 讲师：Dr. Marijan Beg（上午 NumPy）· Dr. Simon Warder（下午 Pandas）

第一部分：NumPy

1. 导入约定与陷阱

import numpy as np            # 惯例缩写
from numpy import *           # ❌ 危险：会覆盖 sum/max 等内置函数

2. 核心概念：ndarray

  • NumPy 最基本对象。
  • list vs array：list 存「指向对象的指针」，array 连续存「值」，所以 array 更快更省内存。
  • 不用内置 array 模块：只支持一维、类型定义不灵活。

3. 创建数组

方法 例子 说明
np.array np.array([1,2,3])；np.array([[1,2],[3,4]]) 从 list 建；同层维度长度须一致
np.zeros np.zeros(3)；np.zeros((3,3)) 全 0
np.ones np.ones((3,3)) 全 1
np.full np.full(shape, value) 填指定值
np.arange np.arange(start, stop, step) 不含终点
np.linspace np.linspace(0,10,6) 指定点数，含终点
np.eye np.eye(3) 单位矩阵

4. 数组属性

a = np.eye(3)
a.ndim      # 2   维度数
a.shape     # (3,3) 各维度大小
a.size      # 9   = np.prod(shape) 元素总数
a.nbytes    # 72  = 9 × 8 字节 占用内存
a.dtype     # float64 元素类型

5. 形状变换

  • .reshape(4,3) / .reshape(3,-1)：改形状，size 不变；-1 自动推断且只能出现一次。
  • .ravel() / .flatten()：展平成 1D（order="K" 按内存存储顺序）。
  • .T：转置。
  • 1D 向量：np.matmul(arr1,arr2) 与 np.matmul(arr2,arr1) 可能不同（行/列向量不严格区分）。

6. 类型（dtype）

  • 自动推断：[1,2.5,3]→float；[1,2,"Hi"]→str。
  • 指定类型：np.array([...], dtype=np.int32)。
  • 陷阱：int_arr[1] = 3.5 会被截断为整数，不报错。

7. 运算与广播

  • 逐元素运算符 + - * / ** %（对应 np.add/subtract/multiply/divide/power/mod）。
  • 矩阵乘法：@ / np.matmul / np.dot。
  • 广播（broadcasting）：不同形状数组可运算，小数组广播到大数组（至少一维兼容）。

8. 索引与切片

  • 多维索引 arr[0,0]；多维切片 arr[1:3,1:6:2]（等价 arr[slice(1,3), slice(1,6,2)]）。
  • 切片赋值 arr[1:3,1:3]=0 按广播规则。
  • ⚠️ 视图陷阱：new_arr = old_arr[1:3,1:3] 是视图（view），改 new 会改 old；用 .copy() 避免。
  • 布尔索引：arr[arr>5]；arr[arr%3==0]=-1。

9. 线性代数（np.linalg）

方法 用途
np.linalg.det(A) 行列式
np.linalg.eig(A) 特征值/特征向量
np.linalg.norm(A) 范数
np.linalg.inv(A) 矩阵求逆（直接法）
np.linalg.solve(A,b) 解矩阵方程（比求逆更稳）

10. 记录数组（Pandas 铺垫）

arr = np.rec.array(...)
arr["val_1"]        # 按名字访问字段
arr.val_2[1]

第二部分：Pandas

11. 导入与 Series

import pandas as pd
  • Series：一维带标签数组，像 NumPy 数组但按标签索引，行为像快速 dict。
  • 创建：pd.Series(data=list) / pd.Series(data, index=labels, name="...") / pd.Series(arr) / pd.Series(dic)（key 自动成为索引标签）。
  • 按标签取值 ser["first name"]。
  • ⚠️ 运算按索引对齐：ser1 + ser2 按索引标签对齐，不是按位置。

12. DataFrame

  • 二维表（像 Excel）：行 = record/index，列 = field。
  • 创建：pd.DataFrame(data, index=[...], columns=[...]) 或用字典 {"列名":[值...]}。

13. 读写

方法 例子 说明
pd.read_csv pd.read_csv("df1.csv") 参数 30+
指定索引列 pd.read_csv(..., index_col=0) 用已有列做索引
to_csv df.to_csv("example", index=False) 写回
pd.read_excel/to_excel read_excel("f.xlsx", sheet_name="Sheet1") 只导数据，不含公式图表

14. 选择（Selection）

  • .columns / .index：列名 / 索引。
  • 选单列 df["Y"]（返回 Series）；选多列 df[["Y","Z"]]。
  • SQL 风格 df.Y：不推荐，有局限。
  • .iloc（位置）：df.iloc[0,:]、df.iloc[:,0]、df.iloc[[1,2],0]（.at 类似）。
  • .loc（标签）：df.loc["A"]、df.loc["B","Y"]、df.loc[["A","B"],["Z","Y"]]。
  • 顺序：loc/iloc 行在前列在后（同 NumPy，与 Python list 相反）。

15. 增删

  • 新建列 df["new"] = df["Z"] + df["Y"]（列就是 Series）。
  • 删除 df.drop("new", axis=1) / df.drop("A", axis=0)：默认非原地，需 inplace=True。
  • del df["col"]：原地删除。

16. 条件筛选

  • df[df>0]、df[df["Z"]>0]、df[(df["X"]>0)&(df["Y"]>1)]（df>0 是布尔 DataFrame）。
  • 多条件用 &（与）、|（或）；每个条件必须加括号。
  • .isin（值在列表）、.isnull/.notnull（判断空值）。

17. 索引操作

  • reset_index()：回到 0,1,2...；set_index("col")：默认非原地，需 inplace=True。
  • MultiIndex：pd.MultiIndex.from_arrays([[...],[...]])；按层取值 mdf.loc["Player 1", :]、mdf.xs("Test 1", level=1)（level 从 0 开始）。

18. 常用操作与统计

  • .head()：看前几行。
  • .unique() / .nunique()：唯一值 / 唯一值个数。
  • .value_counts()：各值出现次数。
  • .duplicated() / .drop_duplicates(inplace=True)：判断/删除重复行。
  • 统计量：.mean() .std() .median() .sum() .max() .min()（注意 numeric_only=True）。
  • .describe()：数据汇总（可 .transpose()）。

19. map 与 apply

  • .map：df["col1"].map(lambda p: p - mean) 逐元素映射，非原地。
  • .apply：df["col1"].apply(f, n=4) 或 args=[4] 传额外参数；可用内置 len。

20. 类型与缺失值

  • .dtype / .dtypes：单列 / 全部列类型。
  • .astype("float64")：转换（非强制 cast）。
  • 类型含义：float64/int64/object（字符串存为 object）。
  • NaN：缺失记为 NaN，总是 float64。
  • 判断：df.isnull() / df.notnull()。
  • ⚠️ 对数学的影响：df.sum() 默认跳过 NaN；df.sum(skipna=False) 传播 NaN。
  • dropna()：按行/列/阈值（axis=1、thresh=2）丢弃。
  • fillna(value="FILL") / df["A"].fillna(df["A"].mean())：填充。
  • replace：把 "Unknown" 等换成 np.nan。

21. 分组与透视

  • df.groupby("Course")：返回 GroupBy 对象。
  • .groups / .get_group("NPP")：查看分组 / 取某组。
  • 聚合：.mean() .std() .max() .min() .count() .describe()。
  • .agg：df.groupby(["Course"]).agg([len,"min","max"]) 自定义聚合。
  • pivot_table(values, index, columns, aggfunc, fill_value)：行列互换聚合；aggfunc 可函数/列表/dict。

22. 合并（combine）

  • pd.concat([df1,df2,df3])：粘合；纵向默认 axis=0，横向 axis=1。
  • pd.merge(left,right,how="inner",on="key")：类似 SQL JOIN。
    • how：inner（交集）/outer（并集）/left（左表全键）/right（右表全键）。
    • 多键 on=["key1","key2"]。
  • .join：left.join(right) 按索引合并列；how="outer"。

23. 可视化

  • .plot.hist()：直方图。
  • .plot.scatter("A","B")：散点图。

24. 时间序列

  • 解析日期：pd.read_csv("Tide.csv", index_col="Date", parse_dates=True, dayfirst=True)。
  • .sample(n=5)：随机采样。
  • 日期分量：df.index.day / .month / .date。
  • .resample("D").mean() / df["Hs"].resample("ME").max()：按日期聚合，可补空缺。
  • .asfreq("ME")：只取时间点不聚合。
  • pd.to_datetime(dates, format="mixed", dayfirst=True, utc=True)：转 DatetimeIndex。
  • 日期歧义：数字日期必须统一 DD/MM/YYYY 或 MM/DD/YYYY。

易错点提醒 ⚠️

  1. np.arange 不含终点，np.linspace 含终点。
  2. NumPy 切片是视图，会改原数组；Pandas 的 drop/set_index/map 默认非原地。
  3. Pandas 多条件筛选必须加括号并用 &/|（不能用 and/or）。
  4. Series 运算按索引标签对齐，不是按位置。
  5. df.sum() 默认跳过 NaN；需要传播时用 skipna=False。
  6. 整数数组赋值浮点数会被静默截断。
