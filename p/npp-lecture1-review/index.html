第一部分：Intro to Computer Science（上午）

1. 为什么是 Python？

  • 解释型、通用目的编程语言，流行且就业需求大。
  • 数据科学领域与 R 竞争，拥有庞大的机器学习/深度学习生态。
  • 「简单的事容易做，复杂的事不算太难，非常复杂的事也有可能做」。

2. Hello World 与命令行

5. 时间/空间复杂度（Big O）

把计算机看作「图灵机」：每个算法都是 空间（内存）与 时间（运行时长）两种资源的权衡。

  • my_max(x)：遍历一遍找最大值 → 时间随长度 线性 增长，记为 $\mathcal{O}(n)$。
  • find_duplicates(x)：双重循环比较 → 平方 增长，$\mathcal{O}(n^2)$。
  • permute(x)：生成所有排列 → 时间与输出空间随长度 阶乘 增长，$\mathcal{O}(n!)$。

衡量时用 %timeit（Jupyter magic）测量运行时间，画 log-log 图看斜率判断复杂度阶。

6. 计算机架构与存储层次

  • 低层：掺杂硅晶片组成晶体管逻辑电路。
  • 存储分层（越往上越快越贵）：CPU 寄存器 → CPU 缓存 → 内存（RAM）→ 硬盘。
  • 层级间搬运数据有时间惩罚 → 计算机处理「靠在一起」的数据更快。
  • 所有现代计算机都是 二进制：高电压「开」/ 低电压「关」。

7. 二进制与整数表示

正整数

十进制 $2381$ 按位权展开；二进制 $1001_2 = 1\cdot8+0\cdot4+0\cdot2+1\cdot1 = 9_{10}$。

int("1001", base=2)   # 9
bin(9)                # '0b1001'
bin(int(3.5))         # 3  -> 不能 bin(3.5)

两种存法：

  1. 存「位数 + 数字本身」→ Python 用此法，支持任意精度整数（受内存限制）。
  2. 固定位数，补前导零 → NumPy 用此法（效率高，配合 C 代码）。

整数溢出（Integer Overflow）

固定位数会溢出。8 位无符号整数 11111111（255）+ 1 会回绕成 0：

import numpy as np
x = np.array([int("11111111", 2)], dtype=np.uint8)   # 255
(x + 1)[0]   # -> 0（溢出回绕）

负数：二补码（Two's Complement）

  • 方法一（符号位）：最高位当符号位，需要单独的加法/减法电路，复杂。
  • 方法二（二补码）：最高位权值取 $-2^{n-1}$。4 位下 $-3 = 1101_2$（$-8+4+1=-3$）。
    • 加法和无符号一样：$-3+3 = 1101+0011 = 0000 = 0$。
    • 取反加一即取相反数：$-3=1101 \to 0010+1=0011=3$。
np.binary_repr(3, width=4)    # '0011'
np.binary_repr(-3, width=4)   # '1101'

8. 字符与文本编码

  • 计算机只能存二进制，字符需编码成数字。
  • 最著名的编码：ASCII（American Standard Code for Information Interchange）。
  • Python 3 默认 Unicode（utf-8），覆盖世界上绝大多数语言的字符。
  • 文本存为「码点（code point）」序列，还需存长度/结束位置。

9. IEEE-754 标准

1985 年 IEEE 制定的浮点标准，解决各厂商表示不一致的问题（此前 $a+b$ 在不同机器结果不同）。

任意非零实数 $x$ 可写为（归一化二进制科学计数法）：

$$x = (-1)^{s} \times (1.f)_{2} \times 2^{e-\text{bias}}$$

  • sign 符号位 $s$：1 位。
  • exponent 指数 $e$：单精度 8 位，双精度 11 位（存的是加 bias 后的值）。
  • mantissa（尾数/significand）$f$：单精度 23 位，双精度 52 位；前导 1 隐式不存，所以有效位多 1 位。
精度 总位数 符号 指数 尾数
single（单精度，float32） 32 1 8 23
double（双精度，float64） 64 1 11 52
quadruple 128 1 15 112

不用死记，用 np.finfo() 查。

单精度（32 位）

$$x = (-1)^s \times (1.f)_2 \times 2^{e-127}$$

  • 指数 $e$：$0 < e < 255$；$e=0$ 保留给 $\pm0$ 与次正规数（subnormal），$e=255$ 保留给 $\pm\infty$ 与 NaN。bias = 127，故 $2^{-126}\le$ 指数 $\le 2^{127}$。
  • 尾数 $m=1.f$：$1 \le m \le 2 - 2^{-23}$。
  • 最大数 $\approx (2-2^{-23})\cdot 2^{127} \approx 2^{128} \approx 3.4\times10^{38}$。
  • 最小正正规数 $= 2^{-126} \approx 1.18\times10^{-38}$；次正规数可到 $2^{-149}\approx1.4\times10^{-45}$（牺牲精度）。

双精度（64 位）

$$x = (-1)^s \times (1.f)_2 \times 2^{e-1023}$$

  • 指数 11 位，bias = 1023；尾数 52 位。
  • 最大数 $\approx 2^{1024} \approx 1.8\times10^{308}$；最小正正规数 $\approx 2^{-1022}\approx2.2\times10^{-308}$；次正规数到 $2^{-1074}\approx4.9\times10^{-324}$。

机器精度 ε（Machine Epsilon）

  • 机器数（machine number）：能精确表示的有限个实数；$x$ 对应的机器数记为 $\mathrm{fl}(x)$。
  • 机器 ε：$1$ 与下一个更大机器数之间的距离。
    • 单精度：$\epsilon = 2^{-23} \approx 1.19\times10^{-7}$。
    • 双精度：$\epsilon = 2^{-52} \approx 2.22\times10^{-16}$。
  • 因为四舍五入到最近机器数，$x > \epsilon/2$ 时 $\mathrm{fl}(1+x)\ne1$ 就成立。

精度与分辨率

  • 单精度 23 位尾数 → $\log_{10}(2^{23})\approx6.9$，可靠 6 位有效数字，分辨率 $10^{-6}$。
  • 双精度 52 位尾数 → $\log_{10}(2^{52})\approx15.65$，可靠 15 位有效数字，分辨率 $10^{-15}$。
import numpy as np
f = np.finfo(np.float64)
print(f.bits, f.nmant, f.nexp)   # 位数/尾数位/指数位
print(f.max, f.tiny, f.eps)      # 最大数/最小正正规数/机器ε
print(f.precision, f.resolution) # 精度/分辨率

10. 舍入、上溢与下溢

  • 每次运算结果都会舍入：$\mathrm{fl}(\mathrm{fl}(a)+\mathrm{fl}(b))$。
  • 下溢（underflow）：小于最小正规数的数先掉精度（次正规数），最终被舍入为 0。
  • 上溢（overflow）：IEEE-754 默认给 $\pm\infty$（如 1e308 * 10 → inf）；某些操作抛 OverflowError（如 2.0**10000、math.exp(1000)）。

11. 五大「惊喜」（Surprises）—— 必须理解

Surprise 1：$1 + x \ne 1$ 却不成立

x = 1e-16
print(1 + x != 1)   # False

原因：$x=10^{-16} < \epsilon/2\approx1.11\times10^{-16}$，$1+x$ 更接近机器数 $1$，被舍入成 1。若 $x=2\times10^{-16}$（$>\epsilon/2$ 但 $<\epsilon$），则 1 + x != 1 为 True。

Surprise 2：$0.1+0.2\ne0.3$

print(0.1 + 0.2 == 0.3)   # False

原因：十进制有限小数未必是二进制有限小数。$(0.1)_{10}=(0.0001100110011\ldots)_2$，像十进制里的 $0.3333\ldots$。fl(0.1)+fl(0.2) 的结果舍入后不等于 fl(0.3)。

Surprise 3：结合律不成立

a, b, c = 1e16, -1e16, 1.0
print((a+b)+c == a+(b+c))   # False

原因：每次运算都舍入。$(a+b)+c = 0+1 = 1$，而 $a+(b+c)=1e16 + (-1e16)$，$b+c$ 舍入回 $-1e16$，结果是 0。机器数在数轴上不均匀分布（越大越稀疏）。

Surprise 4：灾难性消去（Catastrophic Cancellation）

a, b = 1.0000001, 1.0000000
print(a - b == 1e-7)   # False

原因：两个接近相等的数相减。$\mathrm{fl}(1.0000001)$ 本身带极小的舍入误差，减法本身是精确的（Sterbenz 引理），但前导的 1.000000 抵消后，绝对误差不变而结果变小 $10^7$ 倍，相对误差被放大约 $10^7$ 倍。一般地：

$$\text{相对误差}\lesssim\frac{|a|+|b|}{|a-b|}\cdot\frac{\epsilon}{2}$$

  • 减法不产生误差，而是暴露 $a,b$ 里已有的舍入误差；$a,b$ 越接近放大越严重。
  • 对策：改写公式避免相近数相减，如 $\sqrt{x+1}-\sqrt{x}=\dfrac{1}{\sqrt{x+1}+\sqrt{x}}$。

Surprise 5：累加误差

a, b = 100, 0.1
s = 0
for _ in range(a):
    s += b
print(a * b == s)   # False

原因：fl(0.1) 的误差在 100 次迭代中不断累积。

12. 结论（Take-home Message）

永远不要用 == 比较浮点数！ 改用：

$$|a-b|<\text{tol}$$

或直接：

np.isclose(0.1+0.2, 0.3, atol=1e-15, rtol=1e-5)

13. 配套练习要点

  1. dec2bin：整数部分除 2 取余倒序；小数部分乘 2 取整，最多 max_fractional_digits 位（52）防止死循环。
  2. 机器数计数：用 itertools.product 枚举所有位组合，去重后计数。
  3. IEEE-754 编码/解码：给定十进制数求 32/64 位位串，或反过来由位串还原十进制（sign + exponent + mantissa 三段拼接）。
